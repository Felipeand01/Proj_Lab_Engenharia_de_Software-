# Decisões do Projeto

- Stack mantida: React Native + Expo + FastAPI + SQLAlchemy + PostgreSQL.
- Não substituir backend por Supabase.
- O desenvolvimento da TG3 ocorre na branch tg3-implementation.
- Claude Code usa Sonnet 5.5 como padrão.
- Opus é reservado para tarefas complexas.
- Effort padrão: auto.
- Claude pode trabalhar autonomamente apenas em ações locais e reversíveis.
- Commit, push, merge, deploy e alterações destrutivas exigem autorização.
- Segurança deve ser aplicada desde a implementação, não apenas auditada no final.
- Strix será usado como camada final de pentest, não como única proteção.
- UI deve evitar aparência genérica de projeto vibecoded.
- Não usar avaliações falsas, contadores falsos, botões sem ação, links quebrados ou conteúdo fictício apresentado como real.
- Não usar gradiente roxo como estética padrão.
- O app deve priorizar clareza, confiança, contexto urbano, comunidade e mapa.
- Scope creep deve ser evitado: implementar o necessário para concluir corretamente a TG3.
